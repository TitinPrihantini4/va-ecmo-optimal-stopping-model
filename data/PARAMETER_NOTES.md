# Parameter table notes

The CSV retains the original `parameter`, `value`, `status`, and `provenance` columns and all 54 parameter values. Only repetitive descriptive labels were shortened.

## Status legend
- **Literature anchor**: reported clinical anchor from cited literature.
- **Structural**: provisional structural coefficient.
- **Observation / mapping**: provisional observation or mapping coefficient.
- **Decision utility**: provisional decision-utility coefficient.
- **Markov intensity**: provisional Markov transition intensity.

All rows except **Literature anchor** are provisional, not patient-calibrated.

## Provenance legend
- **NC**: calibration against a longitudinal VA-ECMO cohort is still needed.
- **Source 1 / 5 / 7 / 12**: reference identifiers from `Literature_Parameter_Sources.csv` (unchanged).

This is a documentation-only edit. No model code, parameter name, numerical value, or simulation output was changed.
