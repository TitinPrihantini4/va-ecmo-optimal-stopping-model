# VA-ECMO model results

These CSV files are computational outputs from the literature-parameterized VA-ECMO optimal stopping proof-of-concept. They are not patient-level observations or external clinical validation. Synthetic model comparisons are internal only.

Input parameters and Latin hypercube draws belong in `data/`; Python source belongs in `code/`.

Outputs were collected from the previously generated integrated results package. If the model code or parameter settings change, regenerate the results to keep the repository consistent.
